# Security Policy

Specification-Driven Coding privilegia sicurezza by-construction.

## Segnala problemi

Apri una issue privata o contatta il maintainer se trovi istruzioni che potrebbero indurre agenti a:

- esfiltrare dati;
- usare segreti in chiaro;
- concedere permessi write senza controllo;
- bypassare autorizzazioni;
- generare codice pericoloso in sistemi fisici;
- automatizzare azioni sensibili senza human approval.

## Principio

Un agente deve essere capace di spiegare ogni tool call sensibile prima di eseguirla.
