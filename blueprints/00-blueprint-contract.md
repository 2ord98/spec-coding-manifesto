# Blueprint Contract

Template base per ogni Vertical Blueprint Contract.

Base template for every Vertical Blueprint Contract.

## Bilingual field guide

Use the Italian labels as the canonical local structure and the English labels as the operational equivalent for international agents.

| Campo | Field | Meaning |
|---|---|---|
| Nome blueprint | Blueprint name | The contract identifier |
| Modalità | Mode | full project, targeted change, brownfield, app builder, or multi-agent |
| Role frame | Role frame | Technical role, domain, expected quality |
| Product frame | Product frame | Product, primary user, problem, measurable outcome, maturity level |
| Domain frame | Domain frame | Context, terminology, realistic content, constraints, non-goals |
| Assumption ledger | Assumption ledger | Assumption, reason, impact if wrong, reversibility, verification |
| Architecture frame | Architecture frame | Stack, rationale, rejected alternatives, components, integrations, deployment |
| Data frame | Data frame | Entities, input, output, persistence, privacy, retention |
| Security frame | Security frame | Auth, permissions, secrets, validation, logging, human approval |
| UX frame | UX frame | Design direction, patterns to avoid, distinctive interactions, accessibility, states |
| Performance frame | Performance frame | Target, budget, fallback, measurement |
| File contract | File contract | Required files, purpose, required content, checks |
| Execution contract | Execution contract | Implementation order, stop conditions, atomic tasks, required tests |
| Evaluation contract | Evaluation contract | Acceptance criteria, target scorecard, blockers, final audit |
