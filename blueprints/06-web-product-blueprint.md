# Web Product Blueprint

Usa questo blueprint per SaaS, dashboard, portali, strumenti interni, marketplace e web app full-stack.

## Role contract

Agisci come senior full-stack architect. Produci un progetto web specifico, non una dashboard generica.

## Stack selection

Scegli e motiva tra React/Next.js, Vue/Nuxt, Svelte/SvelteKit, Astro, backend separato FastAPI/Laravel/NestJS/.NET/Go, database relazionale o documentale solo se motivato.

## Required contracts

- utenti e ruoli;
- auth e permissions;
- modello dati;
- API contract;
- UI states;
- seed data realistici;
- deploy target;
- logging/error handling;
- security/privacy;
- test.

## Anti-genericity

Ogni web product deve includere almeno tre scelte distintive legate al dominio:

```text
1. decisione UX specifica;
2. dato o workflow specifico;
3. vincolo tecnico specifico.
```

## Output contract

```text
Root folder:
Frontend files:
Backend files:
Database/migrations:
Env example:
Test files:
Run commands:
Deploy notes:
```
