# Continuous Specification Enforcement

This file is a compatibility pointer for earlier documentation plans.

Canonical document: [docs/28-continuous-specification-enforcement.md](28-continuous-specification-enforcement.md)

Continuous Specification Enforcement means the spec, Vertical Blueprint, plan, tasks, implementation, and scorecard are checked as a living contract throughout implementation.

Official pipeline:

Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration
