# Project Types

Questa directory contiene i 20 profili principali. L’agente deve sceglierne uno prima di scrivere la spec.

Regole:

- Un profilo primario è obbligatorio.
- Un secondo profilo è ammesso solo per progetti compositi.
- Più di due profili indicano che il progetto deve essere spezzato.
- Ogni profilo include domande, stack candidates, must-have, anti-pattern e acceptance gates.
