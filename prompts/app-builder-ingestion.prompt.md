# Prompt — App Builder Ingestion

```text
Leggi questa repository come protocollo operativo di Specification-Driven Coding.
Quando ricevi il brief, non generare direttamente.

Prima esegui:
1. mode detection;
2. prompt normalization;
3. project profile routing;
4. clarification pass con massimo 5 domande bloccanti;
5. assunzioni provvisorie;
6. spec sintetica;
7. Vertical Blueprint Contract;
8. plan tecnico;
9. task atomici;
10. scorecard attesa.

Pipeline ufficiale: Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration.

Solo dopo implementa.
Il risultato finale deve includere test/verifiche, punteggio, rischi residui e retro-spec.
```

## English prompt

```text
Read this repository as the operational protocol for Specification-Driven Coding.
When you receive the brief, do not generate directly.

First execute:
1. mode detection;
2. prompt normalization;
3. project profile routing;
4. clarification pass with at most 5 blocking questions;
5. provisional assumptions;
6. concise specification;
7. Vertical Blueprint Contract;
8. technical plan;
9. atomic tasks;
10. expected scorecard.

Official pipeline: Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration.

Only then implement.
The final result must include tests/checks, score, residual risks, and retro-spec.
```
