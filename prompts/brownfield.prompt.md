# Prompt — Brownfield Specification-Driven Coding

```text
Siamo in una repo esistente.
Prima leggi struttura, convenzioni, test, package e pattern esistenti.
Non introdurre nuovi framework o refactor senza motivazione.
Crea spec del cambiamento, non dell’intero sistema.
Ogni task deve indicare i file probabili da toccare e il rischio di regressione.
```
