# Builder Ingestion Prompt

Usa questa repo come instruction layer Specification-Driven Coding.

Use this repository as the Specification-Driven Coding instruction layer.

Prima di generare prodotto o codice:

1. leggi `AGENTS.md`;
2. applica `docs/12-builder-ingestion-protocol.md`;
3. produci intake e specification;
4. scegli il project profile;
5. scrivi il Vertical Blueprint Contract;
6. produci piano e task;
7. implementa;
8. restituisci scorecard.

Pipeline ufficiale: Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration.

Se la richiesta iniziale è incompleta, fai massimo 5 domande bloccanti. Per il resto usa assunzioni dichiarate e reversibili.

## English instruction

Before generating product or code:

1. read `AGENTS.md`;
2. apply `docs/12-builder-ingestion-protocol.md`;
3. produce intake and specification;
4. choose the project profile;
5. write the Vertical Blueprint Contract;
6. produce plan and tasks;
7. implement;
8. return a scorecard.

Official pipeline: Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration.

If the initial request is incomplete, ask at most 5 blocking questions. For everything else, use declared and reversible assumptions.
