# Prompt — Generate Tasks

```text
Genera tasks.md dal piano e dal Vertical Blueprint.
Pipeline ufficiale: Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration.
Ogni task deve essere atomico, ordinato per dipendenza e verificabile.
Formato per task:
- ID
- azione
- input
- output
- verification
- depends on
- human approval, se necessario
Non creare task generici come “implementa backend”.
```
