# Prompt — Specification-Driven Coding Intake

Usa questo prompt quando l’utente dà un’idea grezza.

Se il prompt è già strutturato, non ricostruirlo da zero. Identifica gli elementi riusabili, le assunzioni mancanti, i gate mancanti e solo lo scaffolding minimo necessario.

If the prompt is already structured, do not rebuild it from scratch. Identify reusable specification elements, missing assumptions, missing gates, and only the minimum extra scaffolding needed.

```text
Agisci in modalità Specification-Driven Coding.
Non implementare ancora.
Trasforma il mio prompt in un intake specifico.
Se il prompt contiene già specification, vincoli, stack rationale, acceptance criteria e validazione, preservali e fai solo un pass leggero.

Output richiesto:
1. project profile più probabile tra quelli in project-types/;
2. prompt normalizzato;
3. assunzioni provvisorie;
4. massimo 5 domande bloccanti;
5. non-obiettivi proposti;
6. vincoli anti-genericità;
7. gate che devono passare prima del codice.

Mio prompt:
[INCOLLA QUI]
```
