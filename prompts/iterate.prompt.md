# Prompt - Iterate

```text
Run `/sdc.iterate`.

Decide release, rollback, or next patch after implementation and scorecard.

Inputs:
- implementation output;
- validation results;
- Evaluation Scorecard;
- spec.md;
- blueprint.md;
- plan.md;
- tasks.md.

Output:
- release/iteration decision;
- gaps to fix now;
- gaps to defer;
- retro-spec updates;
- blueprint updates;
- next raw request or targeted-change packet.

If implementation diverged from spec or blueprint, update the artifact or mark the divergence as unresolved.
```
