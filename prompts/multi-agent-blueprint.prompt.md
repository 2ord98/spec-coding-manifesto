# Prompt — Multi-Agent Blueprint

```text
Usando project-types/09-multi-agent-control-system.md e blueprints/05-multi-agent-system-blueprint.md, costruisci il blueprint del sistema multi-agente.

Output richiesto:
- decisione/processo coordinato;
- agent role cards;
- orchestrator/state machine;
- tool registry;
- read/write permissions;
- human approval gates;
- memory/context policy;
- telemetry/evaluation;
- failure modes;
- scorecard.

Non creare agenti senza mandato, input, output, tool e stop conditions.
```
