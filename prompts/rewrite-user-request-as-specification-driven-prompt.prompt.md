# Rewrite Request as Specification-Driven Prompt

Trasforma la richiesta grezza in uno Specification-Driven Prompt.

Non generare codice. Non abbellire soltanto il linguaggio. Compila la richiesta in un prompt costruibile.

Output:

```markdown
# Specification-Driven Prompt

## Intento normalizzato
## Project profile
## Utente primario
## Dominio e contesto
## Non-obiettivi
## Vincoli non negoziabili
## Domande bloccanti, massimo 5
## Assumption ledger
## Stack direction
## Design/product direction
## Output contract
## Acceptance criteria
## Scorecard richiesta
```
