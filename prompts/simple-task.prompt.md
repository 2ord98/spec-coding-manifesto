# Prompt — Simple Task Mode

```text
Lavora in simple-task mode.
Non espandere lo scope.
Prima di modificare:
- normalizza intento;
- identifica file/area impattata;
- dichiara assunzioni;
- proponi patch plan minimo;
- dichiara verifica.

Implementa solo la modifica necessaria.
Alla fine restituisci task scorecard e rischio residuo.
```
