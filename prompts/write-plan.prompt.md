# Prompt — Write Technical Plan

```text
Trasforma spec.md e blueprint.md in plan.md.
Il plan deriva dal Vertical Blueprint, non lo precede.
Pipeline ufficiale: Raw request -> Intake -> Specification -> Project Profile Selection -> Vertical Blueprint -> Plan -> Tasks -> Implementation -> Evaluation Scorecard -> Release/Iteration.
Scegli stack e architettura solo dopo aver motivato:
- perché questa scelta;
- alternativa scartata;
- rischio;
- costo di cambio futuro.
Includi Constitution Check, contracts, testing strategy, implementation slices, risk register, performance budget e deploy/fallback.
```
