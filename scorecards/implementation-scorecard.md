# Implementation Scorecard

Use this scorecard after implementation to evaluate whether the delivered output follows the specification, Vertical Blueprint, plan, and tasks.

| Area | Peso |
|---|---:|
| Aderenza alla specification | 15 |
| Aderenza al blueprint | 15 |
| Completezza file/codice | 15 |
| Sicurezza e privacy | 15 |
| UX/domain fit | 10 |
| Performance/accessibilità | 10 |
| Test/verifica | 10 |
| Manutenibilità | 5 |
| Deploy readiness | 5 |
| **Totale** | **100** |

Gate consigliato:

- 90+: pronto o quasi;
- 75-89: buono con correzioni;
- sotto 75: non pronto.
