# Skills

Le skill sono istruzioni operative riusabili per agenti.

Skill disponibili:

- `specification-driven-coding`: workflow generale.
- `blueprint-compiler`: trasforma richieste incomplete in blueprint eseguibili.
- `project-router`: sceglie project profile e modalità.
- `anti-sameness`: evita output generici.
- `web-app`: applicazioni web.
- `mobile-app`: app mobile.
- `rag-system`: sistemi RAG.
- `multi-agent-control-system`: sistemi multi-agente.

Le skill devono essere usate insieme a spec, blueprint e scorecard.
