# specification-driven-coding-evaluation-scorecard

## Instructions

Use `docs/18-evaluation-scorecards.md` and the relevant file in `scorecards/`.

## Required output

- Overall score 0-100
- Area scores
- Top 5 gaps
- Risks still open
- Patch minima consigliata

## Failure condition

Never mark an output as ready without stating the remaining gaps.
