# specification-driven-coding-project-router

## Instructions

Read `docs/10-project-type-index.md` and choose one primary profile, maximum two for composite projects.

Then choose the execution mode:

- full project;
- targeted change;
- brownfield patch;
- app builder;
- multi-agent system.

## Required reading

- `AGENTS.md`
- `docs/01-manifesto.md`
- `docs/02-methodology.md`
- `docs/10-project-type-index.md`
- relevant `project-types/*.md`
- relevant `blueprints/*.md`

## Required output before implementation

- Intake.
- Project profile.
- Execution mode.
- Blueprint target.
- Clarifying questions or explicit assumptions.
- Spec.
- Vertical Blueprint Contract.
- Plan.
- Tasks.
- Audit gate.

## Failure condition

Do not proceed if the request is still generic and the agent would have to invent critical decisions.
